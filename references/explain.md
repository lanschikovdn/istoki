# Режим «объяснить»: уровни

Объяснение строится только из допущенных тезисов (поле `admitted` после `check_claims.py`), верного синтеза и верных предложений. Если выписок по нужному вопросу нет — сначала режим «разобраться».

В любом формате — тексте, схеме, видео — различие трёх слоёв видно: факт из выписки (A), сопоставление (B), предложение модели (C). На схеме слой B и C — другим стилем рамки и с подписью «синтез» / «предложение ИИ».

Стиль текста везде — `ste-ru.md`.

| Уровень | Что | Когда | Как |
|---|---|---|---|
| 1 | Текст | Всегда | Правила `ste-ru.md`. К каждому утверждению — ссылка `sources/<ключ>.md:<строка>`. |
| 2 | Схема | Есть процесс, структура, сравнение, классификация | Встроенная схема в чате (если у агента есть инструмент показа SVG/виджетов) или SVG внутри HTML. Подписи на схеме — из тезисов, рядом номер тезиса `c4`. |
| 3 | HTML-страница | По запросу | `build_page.py` собирает `index.html` с выписками. Если нужна объясняющая страница поверх неё — отдельный файл `explain.html` с теми же правилами ссылок. |
| 4 | Видео | По запросу | См. ниже. |
| — | Аудио | По запросу | `audio.md`. |

## Видео

Видео собирается в проекте HyperFrames или в совместимом наборе (у пользователя может быть свой набор; путь и правила — в `local.md`).

Порядок:
1. Сценарий — по правилам `audio.md`: каждая фраза со ссылкой на тезис.
2. Проверка ссылок: `speak.py --check-only`.
3. Озвучка: `speak.py` (Silero) или ElevenLabs по просьбе.
4. Раскадровка: одна сцена — один тезис. На экране — цифры и термины из выписки, подпись источника внизу кадра («Водопьянова, 2017»).
5. Сборка и проверка кадров — по правилам набора (`AGENTS.md` набора, если он есть).

Без набора видео не делать: предложить уровень 3 или аудио.
