# Аудиовыпуск

Короткий выпуск на 3–5 минут (примерно 450–750 слов). Это связный рассказ, но **каждая фраза опирается на проверенную выписку**.

## Формат `audio/script.md`

```
# Факты
По данным Водопьяновой, русская версия опросника включает три шкалы. [c4]
В выборке из четырёхсот учителей альфа Кронбаха составила 0,87. [c5]

# Мнения
Маслач считает, что выгорание — ответ на хронический стресс на работе. [c1]

# Противоречия
Авторы расходятся в числе факторов. [c7]
```

Правила:
1. Строка с `#` — заголовок блока. Его читают вслух, ссылка не нужна.
2. Любая другая непустая строка — одна-две фразы и **минимум одна ссылка на тезис** в конце: `[c4]` — id из `claims.json`. Тезис должен пройти проверку. Прямые ссылки на строку источника не принимаются: фраза выпуска опирается только на проверенную выписку. Нужной выписки нет — сначала добавь тезис.
3. Атрибуция — вслух: «по данным…», «… считает», «в исследовании … на выборке …». Слушатель должен слышать, чьё это утверждение.
4. Блоки — в таком порядке: факты, мнения, противоречия. Вступление — одна строка с вопросом исследования. Заключения от себя нет.
5. Числа. Скрипт переводит цифры в слова только в именительном падеже, плюс «в 2017 году» и проценты. Число в другом падеже пиши словами: «на выборке из четырёхсот учителей», а не «из 400». Дробь пиши цифрами («0,87») — её прочитают как «ноль целых восемьдесят семь сотых».
6. Стиль — правила `ste-ru.md`: короткие фразы, действительный залог.
7. **Только кириллица и знаки препинания** для Silero: он молча пропускает цифры и латиницу (проверено 21.10.2026 распознаванием Whisper). `speak.py` остановится и назовёт символы. Фамилии — по-русски («Маслач»), аббревиатуры — как читают («эм-би-ай» для MBI), «α» — «альфа», «p < 0,05» — «пэ меньше ноль целых пять сотых». Отрицательное число («−0,32») скрипт прочитает как «минус…».

`speak.py` проверяет ссылки до озвучки. Если строка без ссылки или ссылка на тезис, не прошедший проверку, — выпуск не собирается.

## Движки

| Движок | Где работает | Чем запускать | Заметки |
|---|---|---|---|
| `silero` (по умолчанию) | Локально, CPU | Python с torch (см. local.md / README) | Модель `v5_ru`, голоса `xenia`, `baya`, `kseniya`, `aidar`, `eugene`. Лицензия моделей CC BY-NC-SA 4.0 — только некоммерческое использование. |
| `elevenlabs` | API | `ELEVENLABS_API_KEY`, `--voice <voice_id>` | Платно. Если у агента есть коннектор ElevenLabs (инструмент генерации речи), можно озвучить им текст из `audio/speech.txt`, не тратя ключ. |
| `edge` | Облако Microsoft | `pip install edge-tts` | Бесплатно, но текст уходит в Microsoft. Голос `ru-RU-SvetlanaNeural`. |

Выход:
- `audio/episode.mp3` — сам выпуск;
- `audio/speech.txt` — текст, который читал голос;
- `audio/transcript.md` — транскрипт со ссылками на файлы и строки.
