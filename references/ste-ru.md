# Ясный русский: правила в духе ASD-STE100

ASD-STE100 (Simplified Technical English) — контролируемый язык для технической документации в авиации. Официальной версии для русского нет. Ниже — адаптация основных правил. Строгость — около 80%: если точность требует длинной фразы, точность важнее.

## Слова
1. Один термин — одно значение. Не заменять термин синонимом ради разнообразия.
2. Новый термин объяснить при первом упоминании одной фразой.
3. Обычное слово лучше иностранного и канцелярского: «делает», а не «осуществляет»; «до», а не «вплоть до момента».
4. Без «воды»: «в целом», «следует отметить», «является важным», «данный».
5. Числа — цифрами, с единицами измерения.

## Предложения
6. Одна мысль — одно предложение.
7. Инструкция — до 20 слов. Описание — до 25 слов.
8. Действительный залог: «Скрипт проверяет цитату», а не «Цитата проверяется скриптом».
9. Глагол, а не отглагольное существительное: «проверить», а не «осуществить проверку».
10. Условие перед действием: «Если ключа нет, скрипт работает с общим лимитом».
11. Без цепочек родительного падежа длиннее трёх слов.

## Структура
12. Шаги — нумерованным списком, один шаг — одно действие.
13. Вывод — первой строкой абзаца.
14. Предупреждение — до шага, к которому оно относится.

## Пример
Было: «Осуществление проверки соответствия цитат производится посредством скрипта при условии наличия файлов источников».
Стало: «Скрипт проверяет цитаты. Для этого нужны файлы источников».

## Где правила не действуют
- Дословные цитаты из источников — всегда как у автора.
- Тексты для других жанров: научная статья, лендинг, официальный документ. Там свои правила жанра.
