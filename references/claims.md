# Выписки: формат и правила

Главное правило навыка: **своего пересказа нет**. Тезис — это короткая подпись к выписке, а не вывод модели. За каждым тезисом стоит дословная цитата и место в файле.

## Формат `claims.json`

```json
{
  "question": "профессиональное выгорание учителей: какие методики измерения сравнивают",
  "sections": [
    {
      "title": "Методики измерения",
      "claims": [
        {
          "id": "c1",
          "kind": "fact",
          "thesis": "Короткая подпись словами автора",
          "evidence": [
            {"source": "Maslach2001_W2117897510", "line": 57, "quote": "дословный текст из файла"}
          ]
        }
      ]
    }
  ]
}
```

Поля:
- `id` — уникален во всём файле: `c1`, `c2`…
- `kind` — один из видов:
  - `fact` — результат или данные: выборка, коэффициент, число;
  - `opinion` — оценка или интерпретация автора;
  - `definition` — определение понятия;
  - `method` — описание методики или процедуры;
  - `contradiction` — авторы расходятся. Нужны выписки **минимум из двух разных источников**.
- `evidence[].source` — имя файла в `sources/` без `.md`.
- `evidence[].line` — номер строки, **на которой начинается** цитата.
- `evidence[].quote` — текст как в файле. Перенос строки внутри цитаты допустим. Можно убрать перенос слова по слогам («выго-рание» → «выгорание»). Остальное — без правок. Пропуск внутри цитаты не допускается: если нужны два куска, это две выписки.

## Правила подписи (`thesis`)
1. Подпись повторяет то, что авторы изучали и писали: та же выборка, те же переменные и термины.
2. Модальность — как у автора: «предполагают» не превращать в «доказано».
3. Без обобщений за пределы выборки и без причинного языка, если у автора его нет.
4. Подпись не добавляет фактов, которых нет в выписках.
5. Чьё мнение — видно из подписи: «По Маслач…», «Водопьянова считает…».

## Цитата
- Длина — до 60 слов. Длиннее — выбрать ключевую часть.
- Цитата из файла со статусом «только аннотация» допустима. На странице она помечается.
- Числа (выборки, коэффициенты, α) брать только из выписки.

## Порядок работы
1. Прочитать файл источника целиком или нужные разделы (Read с номерами строк).
2. Выписать цитату **копированием**, номер строки взять из вывода Read.
3. Запустить `check_claims.py`. Ошибки исправлять по подсказке скрипта: он показывает строку, где цитата найдена на самом деле.
4. Тезис, который не прошёл проверку, на страницу и в аудио не попадает.

## Противоречия
Противоречие — это когда источники расходятся **по одному и тому же вопросу**: разные факторы, разная надёжность шкалы, разные выводы. Не выдумывать противоречие из разницы выборок. Если различие объясняется разными выборками или методиками — так и подписать.
